Local-first contact intelligence

VCF Lookup

Load your contacts CSV, paste the phone numbers you want to check, and get normalized Indian-number matches, duplicate detection, and CSV export. Everything runs in your browser.

100% client-side · no upload

1. Load contacts CSV

Works with the CSV exported from your contacts. Phone fields such as Phone 1 - Value, Phone 2 - Value, and Phone 3 - Value are detected automatically.
Load a CSV to build the in-browser contact index.

2. Numbers to look up

One number per line, or paste a comma-separated list. Indian formats with +91, 91, or leading 0 are normalized to 10 digits.

Privacy model: files are read with the browser File API and processed in memory. No contact data or lookup numbers are sent to a backend.
Deploy this app

GitHub Pages: open repository Settings → Pages, choose Deploy from a branch, select main and / (root), then save. GitHub will publish index.html.

Vercel: import the repository. No build command is required and the output directory is the repository root.

Do not commit your personal contacts CSV to the repository. Upload it through the app after the site opens.
